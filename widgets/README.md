# nankiv on the desktop

A widget is a glance, not a second copy of the app. It answers one question —
*did I make the latest shortlist?* — and a click opens that shortlist in nankiv.

```
                     ┌──────────────────────────────────────────┐
  engine             │ src-tauri/src/{parse,identity,analytics} │
  (all the thinking) │ engine.rs, store/                        │
                     └────────────────────┬─────────────────────┘
                                          │ one function per answer
                     ┌────────────────────▼─────────────────────┐
  shared model       │ src-tauri/src/widget.rs  →  snapshot.json│
  (the contract)     │ widgets/fixtures/*.json                  │
                     └──────┬────────────────────────────┬──────┘
                            │                            │
        ┌───────────────────▼──────────┐   ┌─────────────▼─────────────────┐
  data  │ macos/Core/…/SnapshotSource  │   │ windows/provider (IWidgetProvider)
        │ Glance, Schedule             │   │ SnapshotReader, GlanceState   │
        └───────────────────┬──────────┘   └─────────────┬─────────────────┘
        ┌───────────────────▼──────────┐   ┌─────────────▼─────────────────┐
  views │ macos/Core/…/NankivWidgetViews│  │ windows/cards/*.json (Adaptive)
        └──────────────────────────────┘   └───────────────────────────────┘
```

**Nothing is computed twice.** Every verdict, count, cutoff and branch figure in
a widget was decided by the same Rust functions that draw the app's own screens
(`commands::drive_outcome`). The widgets decode, choose a state, and draw.

**The widget cannot read your data.** The macOS extension is sandboxed with one
read-only exception: the single directory the snapshot lives in. Not the
database beside it. What the snapshot contains is deliberately thin — no Neo
IDs, no registration numbers, no individual CGPAs, and no names except the
labels you typed into your own circle. See [docs/PRIVACY.md](../docs/PRIVACY.md).

**No polling.** The app rebuilds the snapshot when something changes and asks
WidgetKit to reload. Timeline entries exist only for things that change with
time alone: a transient state expiring, a result's turn at the top ending, and
date labels rolling over at midnight.

**A result does not linger.** Twelve hours after an import, the widget stops
leading with it and goes back to resting — the season, what came recently, and
an invitation to drop the next shortlist. The moment it flips travels in the
snapshot (`leads_until`), so macOS and Windows agree without deciding it twice,
and the widget flips on its own with nothing running.

## Layout

| Path | What it is |
| --- | --- |
| `fixtures/*.json` | Snapshots for every state, generated by `src-tauri/tests/widget_fixtures.rs`. Read by the Swift tests, the Xcode previews, the render harness and the Adaptive Card checks. |
| `fixtures/links.json` | The exact `nankiv://` URLs the app accepts. |
| `macos/Core` | Swift package: the snapshot contract (`NankivWidgetModel`), the views (`NankivWidgetViews`), and a render harness. Buildable and testable without Xcode's UI or a signing identity. |
| `macos/Extension` | The widget itself: `@main` bundle, timeline provider, previews. |
| `macos/project.yml`, `macos/NankivWidget.xcodeproj` | Generated by XcodeGen from the spec; the project is committed so a build needs only Xcode. |
| `macos/build.sh` | Builds the universal `NankivWidget.appex` that Tauri bundles into `nankiv.app/Contents/PlugIns`. |
| `windows/` | The Windows 11 widget: Adaptive Card templates, provider, and an honest account of what is and is not built. |

### Why there is nothing to configure

The widget follows the latest shortlist and has no settings. Pinning it to one
shortlist is written and tested (`Glance.make(pinned:)`, and the `removed` state
for when that shortlist is deleted), but it cannot ship yet: a widget with
settings uses `AppIntentConfiguration`, and the system will not hand an intent
configuration to an app built outside Xcode and signed ad hoc. Every timeline
is refused with *"Intent configuration is required but was not provided"*, and
the widget shows its loading placeholder forever. Signing the app with a
Developer ID is the thing that unblocks it; until then the default — which is
what almost everyone wants — is the whole feature.


## Working on it

```bash
npm run widget:test       # Swift model tests against the shared fixtures
npm run widget:renders    # every state × size × appearance, to PNG
npm run widget:build      # the .appex that ships inside nankiv.app
cargo test --manifest-path src-tauri/Cargo.toml --test widget_fixtures
```

Open `widgets/macos/NankivWidget.xcodeproj` for previews: one per widget size,
each a timeline of every state. Step through the entries in the canvas, and use
the canvas's appearance and rendering-mode controls for light, dark, vibrant and
accented.

After changing `project.yml`:

```bash
xcodegen generate --spec widgets/macos/project.yml
```

After deliberately changing the snapshot contract:

```bash
UPDATE_WIDGET_FIXTURES=1 cargo test --manifest-path src-tauri/Cargo.toml --test widget_fixtures
npm run widget:test
```

## The states

Every widget size handles all of them; the fixtures and previews are named after
them.

| State | What the widget shows |
| --- | --- |
| `ready` | The answer, and what the shortlist suggests. |
| `resting` | Twelve hours on, the result stops leading: the season, the recent shortlists, and an invitation to drop the next one. Nothing is hidden — the result heads the list. |
| `importing` | The previous answer, with a line saying a file is being read. |
| `failed` | The previous answer, with a line saying the last import failed. |
| `insufficient` / `not_set_up` | The answer, and why there is no analysis — never a guess. |
| `undetermined` | "Can't tell", and what nankiv needs to tell. |
| `no_identity` | "Finish setting up". |
| `empty` | "No shortlists yet". |
| `removed` | The chosen shortlist was deleted; pick another. |
| `not_started` | nankiv has never run. |
| `needs_refresh` | The snapshot is from another version of nankiv. Open the app. |
| placeholder | Redacted shapes while WidgetKit loads. Never a real answer. |
